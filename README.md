# Fjäder

Fjäder (repository `fjader`) is an open-source, local-first writing app for novels, short stories, manuscripts and scripts. It runs as an installable web app (PWA) on phones and desktops, works offline, exports the formats publishers and productions expect, and lets the writer work with AI models through their own OpenRouter key.

**Status:** specified, not yet built. Three technical spikes have run (`docs/spikes/results/`); their phone checks are still open. The first phase, the prose-writing MVP, is specified as work packages in `docs/specs/`.
